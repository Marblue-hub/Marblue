# 数据边界与限制

- 运输指标衡量源数据 actual_days 与 planned_days 的差，不是最终签收时间。shipping date 是源发运时间。
- First Class 的确定性超期结果需要向数据提供方验证字段及计划规则，不能直接推断承运商、司机、路线、仓库或服务质量原因。
- 订单状态与运输状态有差异；取消包含源数据中疑似欺诈且运输取消的订单。取消销售暴露额不等于确认损失。
- 销售额为用户确认的折扣后 Order Item Total，金额未核验币种。记录利润不是财务净利润，没有真实成本、退款、物流费用或延期损失。
- 全部分析都是描述性关联。不能声称超期导致利润下降、某运输方式造成超期、实际干预有效或节约真实费用。
- 日期覆盖不等于记录齐全。按用户确认，2017-10 及以后月份保留金额趋势，同比/环比列为“待核验”，不计算变化率、不作经营升降结论；2018-01 日期覆盖完整但业务完整性未核验。
- 数据没有仓库产能、承运商、路线、库存流水、供应商主数据、满意度或退款。不能做真实库存优化、调度、采购评级或因果评估。
- 预测和假设情景不在本次 P0 范围。旧版统计检验、情景收益、旧 PBIX 不属于本次验证产物。
- 原始文件在本地，不上传。客户代码只作本地关系键，不含姓名、电邮、密码、街道、邮编或经纬度；发布前仍应审核任何行级衍生文件。

- 本地版本目录名称及数据规模与发布参考一致，不等于有可核验的原始下载链。保留 SHA256、字典指纹与原发布链接；不虚构下载日期或许可证。
